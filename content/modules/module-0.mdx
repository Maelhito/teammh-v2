# Bienvenue dans ton démarrage 🚀

Ce module de démarrage regroupe tout ce dont tu as besoin pour bien commencer,
**avant ton appel de démarrage avec ton coach**.

> Le contenu détaillé (présentation, plan alimentaire, questionnaire) arrive ici.

Une fois ton appel de démarrage effectué, ton coach débloquera l'accès complet à ton programme.
